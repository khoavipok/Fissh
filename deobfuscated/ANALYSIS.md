# Giải mã fm2.txt — Báo cáo đầy đủ

**Kết luận ngắn:** `fm2.txt` là script đã bị bọc bởi VM protector **luast v1.0.1**
(`generated by luast v1.0.1 https://luast.clv.cloud`). "Mã nguồn gốc" mà VM này bảo vệ
**không nằm trong file** — khi chạy, VM tải thư viện UI từ mạng:

```
https://raw.githubusercontent.com/Ngmankhoi/my-hub/main/NexusLib.lua
```

rồi `loadstring()` nó. File đó là **plain-text** (không obfuscate). Bản byte-chính-xác
đã được lấy về git và lưu tại:

- **`deobfuscated/NexusLib.lua`** — payload gốc (104.437 bytes, parse sạch 0 lỗi)
- **`deobfuscated/fm2_static_deobf.lua`** — kết quả khử VM tĩnh bằng Luast-Dumper
- **`deobfuscated/ANALYSIS.md`** — file này

Raw link sau khi push nhánh này:

```
https://raw.githubusercontent.com/khoavipok/Fissh/refs/heads/arena/01a0f254-fissh/deobfuscated/NexusLib.lua
```

## 1. Cấu trúc fm2.txt (5.210.634 bytes, 17.693 dòng)

| Thành phần | Vị trí | Ý nghĩa |
|---|---|---|
| Banner | dòng ~cuối pool | `generated by luast v1.0.1 https://luast.clv.cloud` |
| Bảng hằng `g3H[21.]` | dòng 15 → ~6500 | pool 15.329 entry: số, ciphertext, buffer zstd, hàm con-VM |
| Seed hash `g3H[11]` | pool → được gán runtime | hàm băm chống giả lập môi trường |
| Accumulator `acq` | global | checksum chống-tamper, khoá mọi chuỗi mã hoá |
| Dispatcher CFF | dòng 6516: `__ST = 280; while true do __ST = 6116 - __ST; ...` | vòng lặp trạng thái (control-flow flattening), ~2.581 state |
| `loadstring(abD, "@NexusLib.lua")` | state 6049 (pcall) | bước cuối: chạy payload tải từ mạng |

Trạng thái VM lưu trong **ô bảng** `g3H[167]` (thanh ghi = `g3H[n]`), khác với build
luast mẫu dùng biến local — đây là lý do tool tĩnh cần 2 dòng tiền xử lý (mục 4).

## 2. Kết quả phân tích động (chạy VM trong Luau CLI đã build từ source)

Vì script chỉ chạy đúng trên executor Fluxus (có `fluxus.request`, `getgenv`, buffer, …),
chúng tôi dựng harness giả lập:

- Stub `fluxus.request` ghi log toàn bộ request/response, `_G`/`getgenv` cách ly,
  hook `loadstring` để **dump** code thay vì thực thi.
- `acq` (checksum chống-tamper) được **ép đúng giá trị Windows/Fluxus**
  = `187422423` — nghiệm duy nhất của công thức state 5213:
  `acq*747825 + bxor(acq, 4250498264)*182473 − 894631696548694 = 152`
  (kiểm chứng khớp cả 19 công thức điều hướng PC trong dispatcher).

Kết quả trace từng bước:

1. **Chuỗi fingerprint** (cộng dồn vào `acq`): `Vector2int16` overflow, `readu32` buffer
   zstd, `isfrozen(math)` / `isfrozen(table)` / `isfrozen(buffer)`, độ dài `debug.info`,
   hằng byte… tổng đúng 187.422.423 thì mới đi tiếp — sai là thoát im lặng.
2. **Honeypot**: 6 state bẫy số lớn (4441, 4524, 5152, 5697, 5900, 6047) không bao giờ
   được thực thi trên đường chạy thật.
3. **Hàm băm hạt giống `g3H[11]`** được khôi phục nguyên văn (khớp 100% với bản do
   Luast-Dumper trích tĩnh — xem mục 4):
   `(x + 2654435769) → rs16 → ls5 → rot11 → (+2246822507) → rs13 → ls9 → rot19 → …`
   (8 tầng, mod 2³²).
4. **Hàm giải mã chuỗi** trong các thanh ghi `g3H[215]/[157]/[194]/[182]/[169]`:
   Park-Miller XOR và LCG `S = (S*1597 + 51749) % 2^32`.
5. **State 4967→5095**: lấy `fluxus` rồi `fluxus["request"]` (tên "request" được giải mã
   từ ciphertext pool với key `(state + acq) % 2^32`).
6. **State 6049**: `pcall` hàm con → phát request:
   ```lua
   fluxus.request({ Method = "GET",
       Url = "https://raw.githubusercontent.com/Ngmankhoi/my-hub/main/NexusLib.lua" })
   ```
   Chỉ đọc `resp.Body`, kiểm tra **độ dài** (body 37 byte bị loại, ≥~150KB chấp nhận),
   rồi `loadstring(resp.Body, "@NexusLib.lua")`. Hook loadstring của harness đã dump
   nguyên văn body này → chính là NexusLib.lua.
7. State 4498: `pcall` khởi tạo UI rồi `break` khỏi dispatcher.

**Xác nhận chuỗi đầy đủ (động):** fingerprint → mồi UI giả → GET NexusLib.lua → loadstring.

## 3. Payload NexusLib.lua là gì?

- Thư viện UI thuần Luau: **"Nexus Material Discord / Material You"** của tác giả
  **Ngmankhoi** (cùng repo `my-hub`), ~104KB, đọc sạch, parse 0 lỗi.
- API: `CreateWindow / CreateTab / CreateHeader / CreateSection / CreateToggle /
  CreateButton / CreateDropdown / CreateMultiDropdown / CreateTextbox / CreateSlider /
  CreateStatRow / CreateFeaturedCard / Notify / Get-SetTheme / DestroyAll`.
- Icon Material Symbols nhúng dạng base64: **11 glyph × đúng 3072 ký tự base64
  = 2304 byte = bản đồ alpha 48×48**, vẽ qua `AssetService:CreateEditableImage` + buffer.
- Theme lưu file `NexusWorkspace` (`writefile`/`JSONEncode`), keybind mặc định **RightAlt**,
  kéo thả cửa sổ, minimizer dạng icon nổi. **Không có mã độc** — chỉ là UI lib.
- Chuỗi tiếng Việt trong heap của fm2 cho thấy hub game **"Fishing Master"**
  (auto boss, sell all, unlock đảo, gacha, ESP, key/HWID gating: *"Key hoac thiet bi
  khong hop le"*, *"Executor khong ho tro doc file key, chay o che do offline"*…).

## 4. Kiểm chứng chéo bằng Luast-Dumper (tĩnh, không cần chạy)

Dùng tool công khai `paglsj43dx/Luast-Dumper` (MIT) — static deobfuscator cho luast v1.0.x:

```bash
# Tiền xử lý 2 dòng (fm2 lưu state trong ô bảng thay vì biến local):
#   thay  g3H[167]  ->  __ST     (1.722 chỗ)
#   thay  g3H[21.]  ->  __PT     (1.280 chỗ)
python3 deobf.py fm2_pre.lua --report      # 14/14 test của tool: PASS
```

Báo cáo tool (chạy ~70 giây):

```
banner            : generated by luast v1.0.1 https://luast.clv.cloud
constant pool     : 15329 entries
vm states         : 2581 decoded, 54 live after folding
pool shuffles     : 6 replayed
opaque branches   : 22 folded
anti-tamper stmts : 26 removed
embedded payloads : pool[3533] buffer 28 bytes: 0d08060b000001...
```

- Buffer 28 byte giải nén zstd đọc LE tại offset 0 = **184.944.653** — trùng khớp
  chính xác giá trị trace động của chúng tôi.
- Khôi phục nguyên văn hàm seed-hash `g3H[11]` (khớp 100% mục 2.3).
- Khôi phục probe `HttpService:JSONDecode('{"m":null,"t":"buffer","zbase64":"KLUv/…"}')`
  + `buffer.readu32(buf, 0)` — khớp trace động.
- **Heap chuỗi giải được chứa ngay dòng đầu tiên là URL payload**
  `https://raw.githubusercontent.com/Ngmankhoi/my-hub/main/NexusLib.lua` — khớp run17
  của trace động. Toàn bộ heap xem trong `fm2_static_deobf.lua`.
- Giới hạn của tool trên file này: 0 chuỗi ct đơn lẻ được nội suy (cảnh báo state 1559
  "ciphertext too short"), nên luồng `request`/`loadstring` cuối chưa hiện thành lời gọi
  tường minh — phần đó trace động (mục 2) đã bù đủ.

⇒ Hai phương pháp **độc lập, khớp nhau từng chi tiết**: URL, hàm băm, probe zstd, số liệu pool.

## 5. Đánh giá "khóa bảo vệ" của bạn

| Lớp bảo vệ | Kết quả |
|---|---|
| CFF + trạng thái trong bảng `g3H[n]` | ❌ gỡ được (2.581 state → 54 state sống) |
| Opaque predicates (`x==x`, `0/0==x`, `v*v<0`) | ❌ bị fold (22 nhánh) |
| Chuỗi mã hoá LCG + key theo checksum `acq` | ❌ bị "key-lifting" theo byte-plane, không cần biết `acq` |
| Honeypot / anti-debug | ❌ nhận diện và loại (26 câu lệnh) |
| Fingerprint executor (isfrozen, Vector2int16, debug.info…) | ⚠️ chỉ cản được chạy ngoài Fluxus, không cản phân tích tĩnh |
| Payload thật để ngoài file (tải qua mạng) | ⚠️ né được việc dump tĩnh payload, nhưng URL lộ trong heap — và file nguồn trên GitHub là **plain text** |
| Tên biến/hàm gốc | ✅ mất thật (chỉ còn `v1, v2, g3H[...]`) — nhưng ngữ nghĩa giữ nguyên |

**Trả lời câu hỏi của bạn: CÓ, mã obfuscate luast v1.0.1 của bạn giải mã được.**
Một tool công khai chạy ~1 phút ra khung chương trình + toàn bộ chuỗi; kết hợp trace động
thì khôi phục được cả hành vi cuối (URL + loadstring). Điểm yếu lớn nhất không nằm ở VM
mà ở việc **payload gốc nằm plain-text trên GitHub** — ai cũng lấy được trực tiếp mà
không cần giải mã gì. Nếu mục tiêu là bảo vệ code hub, nên obfuscate chính
`NexusLib.lua`/script hub, hoặc không public repo chứa bản gốc.

```bash
unzip luast-deob.zip && cd luast-deob
pip install numpy zstandard            # tuỳ chọn, chạy nhanh hơn

```
